# 臺南市安南區南興國民小學 115學年度校慶運動大會官方網站

**金獅躍騰・蜈蚣獻瑞・紅寶石綻放南興心**

本專案為臺南市安南區南興國民小學 115學年度校慶運動大會（民國115年12月05日）之官方活動網站與外部長官貴賓線上專屬邀請函系統。

---

## 📌 專案特色與主要頁面

1. **校慶官方網站 (`index.html`)**：
   - **大會主題與理念**：南興三寶（金獅陣、公塭蜈蚣陣、在地番茄紅寶石）與學生四力圖像。
   - **系列暖身週時程表**：11/25 活力慢跑、11/30 趣味賽預賽、12/02 社區走讀踏查、12/03 熱血躲避球賽、12/04 總預演。
   - **12/05 校慶主日精準時刻表**：風雨球場開幕展演 ➔ 戶外操場賽事接續（草地趣味賽 ➔ 鉛球擲遠 ➔ 拔河對抗 ➔ 壓軸大隊接力）。
   - **紅綠藍戰隊即時儀表板**：涵蓋競技分數與「互助合作精神總錦標」四大向度動態評比。
   - **全校人人有獎大摸彩**：120+ 份獎品募集進度展示。
   - **校園平面與安全動線圖**：操場、球場、鉛球安全區、貴賓停車引導。

2. **外部貴賓線上邀請函 (`invite.html`)**：
   - 尊榮燙金請柬視覺（吳宜蓁校長、郭雅婷家長會長仝敬邀）。
   - 智慧出席回條表單（單位、職稱、出席意願、風味午宴葷素、車牌預約、致詞意向、摸彩認捐）。
   - 總務處接待組管理後台（支援即時名單預覽與匯出 CSV 芳名錄）。

## 🚀 GitHub Pages 發布說明

本專案為純 HTML5 + CSS (Tailwind) + JavaScript 架構，無需任何建置或打包流程。
只要在 GitHub Repository 設定中啟用 **GitHub Pages**：
- **Source**: Deploy from a branch
- **Branch**: `main` (或 `master`) / `/ (root)`
即可立即公開上線！
